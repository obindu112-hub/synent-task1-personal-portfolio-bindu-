Personal Portfolio Website

About the Project

This project is a personal portfolio website developed as Task 1 of the Synent Technologies Web Development Internship. It presents my profile, technical skills, projects, and contact information in a simple and professional layout.

Features

- Home Section: Introduces me and provides an overview of my portfolio.
- About Me: Displays my educational background and career interests.
- Skills Section: Highlights my technical skills.
- Projects Section: Showcases my projects and practical experience.
- Contact Section: Provides contact information for visitors.
- Attractive Design: Uses a lavender and purple color theme.
- Responsive Layout: Designed to adapt to different screen sizes.

Technologies Used

- HTML5 – For the structure of the website.
- CSS3 – For styling, colors, layout, and responsive design.
